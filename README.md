🌿 Plant Store - Full Stack Application
This is a comprehensive E-commerce platform for purchasing plants, built using the MERN (MongoDB, Express, React, Node.js) stack. It features a seamless connection between a responsive frontend and a robust backend API.

🚀 Features
Dynamic Product Listing: Displays a variety of plants with real-time data.

Responsive UI: Fully optimized for mobile, tablet, and desktop views.

Shopping Cart: Functional cart logic to add/remove products.

Backend Integration: Custom API endpoints for managing plant data and orders.

🛠 Tech Stack
Frontend: React.js, CSS3, JavaScript (ES6)

Backend: Node.js, Express.js

Database: MongoDB (Optional: Mention if used)

Tools: Git, GitHub Desktop, VS Code
